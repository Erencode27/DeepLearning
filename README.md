Welcome to my Deep Learning repository! This repo documents my learning journey, featuring my **handwritten notes**, step-by-step explanations, and practical Jupyter Notebooks using **TensorFlow**.

The goal is to merge theoretical concepts with practical code to create a solid learning resource.

## 📚 Contents & Notebooks

The notebooks in this repository are structured to take you from basics to more advanced topics:

| File | Description |
| :--- | :--- |
| **`00_tensorflow.ipynb`** | 🏗️ **Introduction:** TensorFlow setup, basic tensor operations, and core concepts. |
| **`02_naural_network_classification...`** | 🔮 **Classification:** Neural network classification problems and model building. |
| **`03_introduction_to_computer_vision...`** | 👁️ **Computer Vision:** Image processing, CNN architectures, and real-world examples. |
| **`vs01. Neural network regression...`** | 📈 **Regression Exercises:** Practical exercises on prediction models. |

## 🎯 Objectives
* Mastering the TensorFlow library.
* Understanding Neural Network logic.
* Solving Classification and Regression problems.
* Learning the fundamentals of Computer Vision.

## 🛠️ Requirements & Tech Stack

To run this project locally, you will need the following libraries:

* **Python 3.8+**
* `tensorflow` (2.x)
* `numpy` & `pandas` (Data manipulation)
* `matplotlib` (Visualization)
* `scikit-learn` (Modeling tools)
* `pillow` (For image processing)

## 🚀 Installation & Usage

Follow these steps to clone and run the project on your machine:

### 1. Clone the Repository
```bash
git clone [https://github.com/Erencode27/DeepLearning.git](https://github.com/Erencode27/DeepLearning.git)
cd DeepLearning
2. Create a Virtual Environment (Recommended)
Linux / macOS
python -m venv venv
source venv/bin/activate
 Windows
python -m venv venv
venv\Scripts\activate

Install Dependencies
pip install tensorflow numpy pandas matplotlib scikit-learn pillow jupyter

## 4. Run the Notebooks
To start locally, run the following command in your terminal:

jupyter notebook
Alternatively, you can upload and run the .ipynb files directly on Google Colab.
